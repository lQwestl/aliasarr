Безопасность и авторизация

Вход по логину и паролю защищает веб-интерфейс. Внешние API-запросы продолжают работать по X-Api-Key заголовку.

Разрешает доступ к веб-интерфейсу без ввода логина и пароля с локальных и приватных IP-адресов (localhost, 127.0.0.1, 192.168.x.x, 10.x.x.x, 172.16-31.x.x). Только главный администратор может изменять эту настройку.

Защита аккаунтов одноразовыми 6-значными кодами из приложений-аутентификаторов. 2FA запрашивается исключительно при входе через внешний IP-адрес (при входе с приватных IP локальной сети 2FA не запрашивается).

Безопасный протокол HTTPS (SSL)

HTTP

Шифрование трафика веб-интерфейса через встроенный самоподписанный SSL-сертификат. Сертификат выпускается на максимальный срок (100 лет / 36500 дней) и автоматически перевыпускается при истечении срока.

Сброс пароля Администратора в Docker

Если пароль утерян или забыт, вы можете сбросить его прямо из хост-системы одним из следующих способов:

1. Через команду терминала Docker (рекомендуется): 
docker exec -it aliasarr python -m app.cli reset-admin --password "YourNewPassword"
Если опустить параметр --password, система сгенерирует надёжный случайный пароль и выведет его в консоль.
2. Через переменную окружения в docker-compose.yml: 
environment:
  - ALIASARR_ADMIN_PASSWORD=my_secret_pass
3. Через файл-триггер в примонтированной папке /config:

Создайте файл /config/reset_admin_password.txt с новым паролем. При следующем старте контейнера Aliasarr применит пароль и удалит файл.

Добавить источник метаданных

Sonarr SkyHook (Serials/Anime):

Официальный облачный сервис Sonarr. Работает «из коробки» без API-ключей, предоставляет метаданные TheTVDB, TMDB, AniList для сериалов и аниме.

Radarr SkyHook (Films):

Официальный облачный сервис Radarr для фильмов. Работает «из коробки» без API-ключей, загружает альтернативные названия (AlternativeTitles), переводы (Translations), постеры, даты кинопроката и цифрового релиза для фильмов.

Как получить ключ TMDB:
  1. Зарегистрируйтесь на themoviedb.org
  2. Откройте Settings → API
  3. Скопируйте Read Access Token (v4 auth) — это длинная строка eyJ...

Важно: вставляйте именно Read Access Token (eyJ...), а не короткий API Key v3.

TheTVDB API v4:

Для использования TheTVDB введите API Key v4 из личного кабинета thetvdb.com. Если у вас подписка со Subscriber PIN, укажите PIN в поле ниже.

TVMaze:

Если у вас есть аккаунт TVmaze, для Premium-функций введите ваш_логин:ваш_API_ключ. Ключ можно найти на tvmaze.com/dashboard.

Если ничего не выбрано — загружаются алиасы для всех стран мира.
